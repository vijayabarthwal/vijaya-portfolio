Project Case Study

Personal Portfolio Website

A responsive personal portfolio created to showcase my education, digital skills, practical projects, and professional growth while building my experience in web development.

View Live Website ↗ View GitHub ↗

Project Goal

I wanted to create a professional online presence that brings together my business education, digital skills, learning journey, and practical work in one place.

The Challenge

The website needed to present my skills and projects clearly while remaining professional, easy to navigate, responsive across devices, and simple to update as I continued learning.

My Approach

01 — Structure

Organized the portfolio into introduction, skills, projects, education, and contact sections.

02 — Interface

Built the structure with HTML and created the visual design and responsive layout with CSS.

03 — Projects

Added practical projects and learning areas to create a clear, recruiter-friendly portfolio.

04 — Publish & Test

Used GitHub and GitHub Pages to manage, publish, test, and improve the website.

Technologies

HTML CSS GitHub GitHub Pages Responsive Design

Problem Solving

A key part of the project was learning to identify and correct problems during development rather than stopping at the first working version.

My workflow became: build → test → identify → fix → verify

What I Learned

This project gave me practical experience with HTML, CSS, responsive design, GitHub, version control, and publishing a live website.

More importantly, it taught me how to turn an idea into a working digital product and improve it through testing and iteration.

Outcome

The finished portfolio provides a professional online presence that I can continue expanding with new projects, skills, and creative work.
